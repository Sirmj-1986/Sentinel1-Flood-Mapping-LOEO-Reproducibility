# Processed reproducibility data

This directory contains the compact processed tables required for
core numerical reproduction of the associated flood-mapping study.

## Files

### loeo_12predictor_table.csv
Archived Leave-One-Event-Out development and held-out partitions using
the final 12-predictor feature set.

### otsu_heldout_predictions.csv
Final event-specific adaptive Otsu predictions at the independent
held-out reference pixels.

Values 0 and 1 represent non-flood and flood respectively.

The files are derived from the validated analysis products used in the
associated manuscript. Original source files remain unchanged.
